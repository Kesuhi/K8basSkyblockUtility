# Language classification (R30, 2026-10-05)

Every source file, with the language it fits best. The criteria, applied in order (the first that applies decides):

1. **Java by hard constraint:** mixins, accessors and invokers; anything an annotation processor reads; anything accessed by reflection or by exact bytecode signature (Gson reads the config, rule and database classes by reflection); manifest entry points, unless the loader documents Kotlin support (Fabric Language Kotlin supports plain Kotlin classes).
2. **Kotlin** for state that may be absent, single-instance managers and trackers (`object`), data holders (`data class`), collection transforms, branch-heavy parsing (`when`), and overloads that default arguments replace.
3. **Java** for public API that plain Java callers or other mods use, per-frame or per-tick hot loops where Kotlin would add boxing or allocation, and code that is mostly calls into Java APIs.
4. **No clear winner:** the file stays as it is.

"Move" files are converted in PLAN T2.10b–T2.10i; their Java-facing API stays as it was. Reviewed by five reviewers and a completeness critic: 73 move, 185 stay Java, 17 are left as they are.
